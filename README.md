# NCT Cinema

Hệ thống xem lịch chiếu, đặt vé xem phim và quản trị rạp phim.

| Thư mục | Nội dung |
| --- | --- |
| `frontend/` | Next.js 16, React 19, TypeScript, Tailwind CSS 4, shadcn/ui, TanStack Query |
| `backend/` | Spring Boot 4.1, Spring Security (session + CSRF), JPA, MySQL hoặc H2 local |

## Cài công cụ portable & chạy thử

```powershell
.\CAI_DAT.bat
```

- Backend: chạy `CHAY_BACKEND.bat`
- Frontend: chạy `CHAY_FRONTEND.bat`
